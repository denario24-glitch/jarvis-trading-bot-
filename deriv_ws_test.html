How to read this

If a test says OPEN + PING RESPONSE, the browser can reach that endpoint. If both end with code 1006, the browser/network path may be blocking or aborting the handshake; this test alone cannot prove which network component is responsible. If the socket opens but returns a JSON API error, read that error in the log.

App ID 1089 is a testing ID shown in Deriv's examples. Register your own app ID before public release.
